\# Simulation numérique d'une chute libre



Projet de physique numérique réalisé en Python dans le cadre de ma L3 Physique.



\## Objectifs



\- Simuler une chute libre dans le vide.

\- Comparer les solutions numérique et analytique.

\- Calculer les erreurs numériques.

\- Étudier une chute avec frottements quadratiques.

\- Déterminer la vitesse limite.

\- Étudier l'influence de la masse.



\## Outils utilisés



\- Python

\- NumPy

\- SciPy

\- Matplotlib
